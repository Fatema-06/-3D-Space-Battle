A real-time 3D fighting game built with OpenGL and GLUT, featuring physics-based spaceship combat with dynamic lighting and particle effects.

## ✨ Features

- **Two-player competitive gameplay** (Player 1 vs Player 2)
- **Detailed 3D spaceship models** with realistic movement physics
- **Dynamic lighting** with specular highlights
- **Particle effects** for engine trails and explosions
- **Collision detection** between ships and projectiles
- **Sound effects** (optional - requires integration)

## 🛠️ Technologies

- **OpenGL** (Core rendering)
- **GLUT** (Window/input management)
- **C++** (Game logic)
- **GLM** (Math operations)
